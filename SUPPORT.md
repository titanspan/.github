# Support

- Use a project's **Discussions** for questions and design conversations.
- Use a project's **Issues** for reproducible defects and actionable requests.
- Review the project's README and documentation before opening a support
  thread.
- Report security concerns privately using the affected repository's Security
  tab, as described in [SECURITY.md](SECURITY.md).

Support is provided by community contributors on a best-effort basis. No
commercial support service or response-time commitment is offered.
