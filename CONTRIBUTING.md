# Contributing to Titanspan

Thank you for contributing. Each repository may provide project-specific
guidance; read that guidance before opening an issue or pull request.

## Before contributing

- Search existing issues and discussions before opening a new topic.
- Describe the user problem and the change you propose.
- Keep pull requests focused and include tests or documentation when relevant.
- Do not include credentials, private data, or unrelated changes.

## Pull requests

Explain the purpose of the change, link related issues, and call out testing,
security, compatibility, and performance effects. Follow the repository's
checks and respond to review comments before merging.

## Community expectations

Treat contributors with respect and follow the organization Code of Conduct.
Use the affected repository's Discussions for design questions and Issues for
actionable defects or requests.
