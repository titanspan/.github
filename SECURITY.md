# Security Policy

Report a vulnerability privately through the **Security** tab of the affected
Cyber Cosmos repository using its private vulnerability reporting form. Do not
publish an unpatched vulnerability in a public issue or discussion.

Include the affected repository and version or commit, impact, reproduction
steps, and any safe mitigation you have identified. Maintainers will use the
private advisory to coordinate investigation and disclosure.

For Titanspan-specific guidance, see
https://github.com/Cyber-Cosmos/titanspan/blob/main/SECURITY.md.
